# 게임 효과음

현재 실행에는 외부 음성·효과음 파일이 필요하지 않습니다. `src/feedback-sound.js`에서 직접 작성한 PCM 합성 함수를 사용합니다.

- 타격음: 음정 없는 짧은 퍼커션.
- 첫 10콤보: 가벼운 0.30초 전자 스윕.
- 50·100·150…콤보: 전자 질감을 더한 0.48초 스윕.

짧은 시작·끝 페이드와 피크 제한을 적용하고 작은 음량으로 음악에 섞습니다. 음악 재생 시각·판정·음악 음량은 바꾸지 않습니다. 두 콤보 버퍼를 오디오 장치의 샘플레이트로 한 번 합성해 캐시합니다. 구간별 보상은 곡당 한 번, 새 플레이에서 초기화됩니다. 설정에서 두 효과음을 따로 들어보고 콤보 음량을 조절할 수 있습니다.

이 공개 스냅샷에는 시스템 TTS·외부 음성 샘플·개인 음원이 포함되지 않습니다.
