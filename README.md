# PULSE SHIFT

세 오리지널 곡을 연주하는 브라우저 리듬 게임입니다. **PULSE SHIFT** 타이틀 아래에서 LP 턴테이블과 양옆 앨범 커버로 곡을 고르고, 원근 레인으로 다가오는 노트를 D·F·J·K로 입력합니다. 중앙 LP는 앨범 아트로 가득 채우며, 곡을 선택하면 해당 곡의 8마디 미리듣기가 자동으로 반복됩니다. 버전 0.6.0이며 기본 4키와 AFTERGLOW LEVEL 1·ASTRAL VEIL LEVEL 3의 6키 실험을 제공합니다.

소스 저장소: [perspicacia/pulse-shift-demo](https://github.com/perspicacia/pulse-shift-demo). 이 주소는 소스 검토용이며 게임은 아래 명령으로 로컬에서 실행합니다. 검증 절차와 한계는 [DEMO.md](DEMO.md), 포함 기능은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

발표 시연: [ASTRAL VEIL 6키 LEVEL 3 ALL PERFECT MP4 다운로드](https://github.com/perspicacia/pulse-shift-demo/releases/download/demo-astral-6k-2026-10-07/ASTRAL_VEIL_6KEY_LEVEL3_ALL_PERFECT.mp4) · [릴리스 설명](https://github.com/perspicacia/pulse-shift-demo/releases/tag/demo-astral-6k-2026-10-07). 1080p·60fps·약 81초이며 음악·타격음·콤보 효과음을 포함합니다. 같은 게임 코드를 발표용 Canvas 화면으로 렌더한 **자동 입력 시연**이며 실제 브라우저 화면 녹화나 사람의 플레이 기록은 아닙니다. 757 PERFECT·0 MISS·100만 점·정확도 100%를 확인했습니다. MP4는 릴리스 첨부파일로 제공하고 발표 PDF는 로컬에 유지합니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 런타임 패키지가 없어 `npm install`은 필요하지 않습니다.

```sh
git clone https://github.com/perspicacia/pulse-shift-demo.git
cd pulse-shift-demo
npm run dev
```

서버가 실행되면 같은 컴퓨터의 Chrome 주소 표시줄에 `http://localhost:4173`을 입력합니다. 실행 터미널은 유지하고 종료할 때 `Ctrl+C`를 누릅니다. 서버가 브라우저를 자동으로 열지는 않습니다. 포트가 사용 중이면 `PORT=4183 npm run dev`로 실행하고 `http://localhost:4183`을 엽니다. 다른 컴퓨터에서는 이 컴퓨터의 localhost 주소로 접속할 수 없습니다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 왼쪽부터 4개 레인 | D · F · J · K |
| AFTERGLOW LEVEL 1 / ASTRAL VEIL LEVEL 3의 6키 실험 | S · D · F / J · K · L |
| 곡 선택 | 메뉴에서 ← · → 또는 플레이어의 좌우 버튼 / 커버 클릭 |
| 일시정지 / 재개 | Esc |
| 곡 시작 / 일시정지 후 재개 | Enter 또는 화면 버튼 |
| 터치 입력 | 플레이 화면 아래의 레인 버튼 |

키를 계속 누르고 있어도 노트가 자동으로 처리되지 않습니다. 동시 노트는 각각의 키를 함께 누릅니다. 창이 포커스를 잃거나 다른 탭으로 이동하면 자동으로 일시정지됩니다.

기본은 4키입니다. **6키 실험**은 AFTERGLOW LEVEL 1(최대 두 동시 노트)과 ASTRAL VEIL LEVEL 3(757노트·최대 세 동시 노트)에서 선택할 수 있습니다. 곡에 맞는 지원 난이도를 자동 선택하며 TIDAL CIRCUIT을 고르면 4키로 돌아옵니다. 점수 기록은 `곡:4k:레벨`과 `곡:6k:레벨`로 분리하며 이전 4키 기록도 계속 읽습니다. 마지막으로 고른 키 모드는 설정에 저장되므로 기본 시연 전에는 **4 KEY · 기본**을 선택하세요. 자세한 범위와 검증은 [DEMO.md](DEMO.md)를 확인하세요.

## 포함된 기능

- 오리지널 곡 **AFTERGLOW** — PULSE LAB, 148 BPM, 약 67초.
- 오리지널 곡 **TIDAL CIRCUIT** — PULSE LAB, 132 BPM, 약 76초. 모듈러 신스·깊은 베이스·스윙이 있는 브로큰 비트.
- 오리지널 곡 **ASTRAL VEIL** — PULSE LAB, 126 BPM, 약 72초. 어두운 전자 베이스·별빛 아르페지오·넓은 패드와 합성 코러스.
- 4키 LEVEL 1 / LEVEL 2 / LEVEL 3 난이도와 일반 노트, 동시 노트. 6키 실험은 AFTERGLOW LEVEL 1과 ASTRAL VEIL LEVEL 3 지원.
- 노트 속도 ×1.0–×6.0, 싱크 보정 −200–+200 ms.
- 판정선의 팝·링·별빛 입자와 판정·콤보 팝 애니메이션, 음정 없는 짧고 부드러운 타격음.
- 첫 10콤보와 이후 50·100·150콤보의 축하 효과음·배너·컨페티. 같은 구간은 곡당 한 번만 보상.
- 일반 PERFECT·GREAT·GOOD 입력에는 짧은 타격음과 화면 판정만 표시.
- 음악·타격음·콤보 효과음의 개별 볼륨, 타격 이펙트 강도와 타격음·콤보 효과음 미리듣기.
- 판정, 콤보, 최고 콤보, 정확도, 점수, 결과 등급.
- 곡별·키 개수별·레벨별 최고 기록과 설정을 브라우저의 로컬 저장소에 저장.
- 곡 선택 즉시 8마디 자동 미리듣기, 수동 정지·재생, 시작 카운트다운, 일시정지, 재시도, 곡 선택으로 복귀.
- LP 원판 전체를 채우는 전용 아트와 양옆 앨범 커버. 큰 화면의 측면 커버를 약 17% 확대하고, 좁은 화면에는 축소 배치를 적용. 좌우 키로 중앙에 넣고 Enter로 시작하며 미리듣기 중에는 디스크가 회전.
- 별도 심볼 없이 큰 PULSE SHIFT 워드마크를 사용하는 헤더. TRACK SELECT보다 타이틀을 강조하고 작은 화면에서도 한 줄 전체에 표시.
- 작은 화면 대응과 터치 레인 버튼, 키보드로 조작 가능한 메뉴.

## 오리지널 곡 선택

첫 대기 화면의 **LOBBY RADIO — NEON HALO**는 128 BPM의 오리지널 사이버 팝 루프입니다. 반짝이는 FM 아르페지오, 넓게 퍼지는 신스 패드, 음성처럼 들리는 합성 코러스, 엇박 베이스와 디지털 퍼커션으로 구성됩니다. Grimes의 [Artificial Angels 공식 영상](https://www.youtube.com/watch?v=tvGnYM14-1A)을 분위기 참고로 삼았으며, 음악과 코러스는 코드로 새로 합성합니다.

브라우저의 자동재생 제한 때문에 **첫 클릭이나 키 입력** 뒤에 시작합니다. 곡을 직접 고르기 전에는 NEON HALO가 흐르며 **켜기 / 끄기**와 설정의 **기본 대기 음악 볼륨**을 사용합니다. 곡을 고르면 대기 음악이 멈추고 **선택한 곡의 8마디 미리듣기 구간이 자동으로 반복**됩니다. 상단 메뉴 음악 카드도 선택곡의 제목과 상태로 바뀝니다. 선택곡은 **음악 볼륨**으로 조절하며 메뉴 카드 또는 플레이어의 미리듣기 버튼으로 정지·재생합니다. 직접 정지한 곡은 설정이나 탭에서 돌아와도 저절로 켜지지 않습니다. 다른 곡을 선택하면 새 곡의 미리듣기를 시작합니다. 설정·플레이 방법·숨겨진 탭·게임에서는 메뉴 음악을 멈추고, 메뉴 조건이 회복되면 선택곡을 재개합니다. 미리듣기는 별도 오디오 소스를 사용하고 플레이 음악의 판정 시계를 바꾸지 않습니다.

상단 **LP 턴테이블**에서 **←·→** 키, 좌우 이동 버튼 또는 양옆 커버를 눌러 **AFTERGLOW**·**TIDAL CIRCUIT**·**ASTRAL VEIL**을 고릅니다. 세 커버가 중앙과 양옆에 하나씩 놓이며 첫 곡과 마지막 곡 사이에서도 순환합니다. 중앙에 올라간 LP가 선택된 곡입니다. 제목, BPM, 길이, 채보, 최고 기록이 함께 바뀌며, 방향키로 이동한 뒤 **Enter**로 바로 시작할 수 있습니다. 빠르게 곡을 넘겨도 마지막 선택이 유지되고, 설정의 슬라이더와 플레이 중 입력에는 곡 이동 키가 적용되지 않습니다.

곡 선택과 함께 LP가 회전하고 실버 톤암이 판 위로 이동합니다. 선택곡 미리듣기는 음악에 맞춘 8마디 구간을 반복하며 경계에 짧은 크로스페이드를 적용합니다. 앨범 아트는 **LP 원판 전체**에 표시합니다. 중앙 원판용 SVG는 제목과 정보를 원형 안에 배치하고, 양옆 커버와 플레이 배경은 기존 정사각형 앨범 아트를 사용합니다. 멈추거나 곡을 바꾸면 톤암이 돌아옵니다. 시스템의 ‘동작 줄이기’ 설정에서는 커버 이동·회전·톤암 이동 애니메이션을 끕니다. 오리지널 곡은 최초 사용 시 워커에서 합성하고, 이후에는 곡별 캐시를 재사용합니다.

**TIDAL CIRCUIT**은 Bonobo의 ID700을 참고해 모듈러 신스와 영국풍 전자음악의 분위기를 바탕으로 작곡한 새 오리지널 곡입니다. 자체 FM 플럭, 마이너·메이저 확장 화음, 서브 베이스, 엇박 킥과 스윙 하이햇을 사용하며, 인트로 → 그루브 → 브레이크다운 → 두 번째 그루브 → 아웃트로로 구성됩니다. 원곡의 음원이나 샘플을 사용하지 않습니다. 참고: [Bonobo의 공식 트랙 소개](https://music.apple.com/us/album/distance-in-static/1895659203).

TIDAL CIRCUIT의 LEVEL 1·2·3 채보는 각각 85·168·381개 노트로 구성됩니다. 합성과 채보가 동일한 악기 이벤트를 공유하므로, 스윙과 엇박도 실제 악기가 나오는 시점에 맞춰집니다. 기본 곡의 이전 버전 기록도 AFTERGLOW에서 이어서 볼 수 있습니다.

**ASTRAL VEIL**은 Emmon의 [Black light 공식 트랙](https://emmon.bandcamp.com/track/black-light)을 분위기 참고로 삼은 우주적인 다크 일렉트로 오리지널입니다. 4박 킥과 펄스 베이스에 FM 아르페지오, 디튠 패드, 가사 없는 합성 코러스와 스테레오 에코를 겹칩니다. 인트로 → 그루브 → 상승 → 부유하는 인터루드 → 비트 복귀 → 아웃트로의 36마디 구성입니다. 외부 음원이나 샘플 없이 워커에서 합성하며 LEVEL 1·2·3은 63·243·599노트입니다. 음악과 채보는 `src/astral-score.js`의 악기 시점을 함께 사용합니다.

## 시작 화면의 사이버 도시

시작·곡 선택 화면은 달빛, 고층 건물과 청록·붉은 네온이 있는 정적 도시 배경을 사용합니다. Codex 내장 ImageGen으로 새로 만든 그림을 약 485 KiB JPEG로 압축했으며 [생성 방식과 프롬프트](assets/neon-city.README.md)를 함께 제공합니다. 참고 스크린샷 자체를 배경 파일로 사용하지 않습니다.

`menu-background.css`가 어두운 오버레이·반투명 메뉴 패널·작은 화면 크롭을 담당합니다. 배경은 입력을 가로채지 않으며 플레이·결과 화면에서는 숨깁니다. 이미지 로드 실패 시에도 어두운 단색 배경과 메뉴가 남습니다. 실행 중 이미지 생성이나 외부 API 호출은 없습니다.

도시 배경과 LP 메뉴의 이전 회귀 검증 기록은 [DEMO.md](DEMO.md)에 있습니다.

## 앨범 배경과 원근형 플레이 화면

선택한 곡의 앨범 커버를 무대 전체 배경으로 사용합니다. 커버 불투명도는 `playfield.css`의 `--album-opacity: .28`이며, 어두운 그라데이션을 겹쳐 노트와 판정선이 구분되게 합니다. 세 곡은 각자의 커버를 사용합니다. 배경 이미지는 장식이며 입력을 가로채지 않습니다.

레인·노트·박자선은 같은 원근 좌표로 그립니다. 멀리서 작게 나타난 노트가 판정선으로 다가오며 커지고, 정확한 노트 시각에 각 입력 버튼의 중앙을 지납니다. 표시 방식만 변경하며 판정 범위·채보·오디오 출력 시계·점수 공식은 유지합니다. 타격 입자는 판정선의 같은 좌표에서 발생합니다. 점수와 정확도는 상단, 콤보는 레인 옆에 표시하고 작은 화면에서는 보조 정보를 줄입니다. 4키와 6키 모두 같은 무대 구조를 사용합니다.

사용자가 제공한 화면은 원근 레인과 무대 구성의 참고로만 사용했습니다. 배경·커버는 프로젝트의 기존 SVG이며 참고 게임의 이미지·음원을 추가하지 않았습니다.

헤더의 PULSE SHIFT는 굵고 기울어진 각진 글자와 신호 절개·스피드 라인을 직접 그린 라임색 SVG 워드마크입니다. 왼쪽 파형 아이콘을 제거하고 **TRACK SELECT보다 크게** 표시합니다. 작은 화면에서는 타이틀을 한 줄 전체에 배치하고 설정·도움말은 별도 줄에서 조작합니다. 외부 폰트 없이 표시합니다. 홈 링크의 접근성 이름은 `PULSE SHIFT 홈`으로 유지합니다. 턴테이블·로고는 참고 이미지의 형태와 분위기를 CSS와 SVG로 새로 그렸으며, 사진·인물·기존 상표 그래픽을 포함하지 않습니다.

헤더 홈 링크·도움말·설정은 키보드로 조작할 수 있으며 설정·도움말 버튼은 44px를 유지합니다. 320px·375px 화면에서도 가로 넘침 없이 타이틀과 곡 선택을 표시합니다.

파비콘은 `assets/favicon-disc.svg`의 직접 그린 반사광 CD입니다. 게임의 라임·청록·실버를 사용하고 가운데 구멍과 바깥 영역은 투명하게 처리했습니다. 작은 브라우저 탭에서도 선명하도록 SVG로 연결합니다.

## 타격 효과와 콤보 효과음

콤보 효과음은 **연속 10콤보, 이후 50·100·150…콤보**에서만 나옵니다. PERFECT·GREAT·GOOD 모두 콤보를 이어가고 MISS는 끊습니다. 콤보가 끊겼다가 같은 구간에 다시 도달해도 이미 받은 보상은 반복되지 않습니다. 다시 플레이하면 보상 일정도 초기화됩니다. 일반 판정이나 누적 PERFECT 횟수만으로는 콤보 효과음이 나오지 않습니다.

플레이 화면의 **COMBO REWARD**는 다음 미획득 보상까지의 연속 콤보를 표시하며 MISS 시 진행량이 줄어듭니다. 해당 곡의 노트 수로 도달 가능한 보상을 모두 받으면 ‘보상 완료’로 표시합니다.

콤보 효과음은 코드로 직접 합성합니다. 첫 10콤보에는 가벼운 0.30초 전자음을, 50콤보 이상에는 조금 더 풍성한 0.48초 전자음을 재생합니다. 낮은 음량으로 음악에 섞으며 음악 음량이나 재생 시계를 바꾸지 않습니다. 외부 음성 파일을 내려받지 않고 두 버퍼를 캐시합니다. 효과음 구현은 [assets/sfx/README.md](assets/sfx/README.md)에 설명합니다.

모든 레인의 타격음은 음정 없는 짧은 퍼커션이며 조용한 구간에서는 더 작아집니다. 설정의 **타격음 듣기 / 10콤보 듣기 / 50콤보 이상 듣기**로 확인하고 음악·타격음·콤보 효과음 음량을 따로 조절할 수 있습니다. 콤보 효과음 0%는 재생 중인 효과음도 정리합니다. 재시도·곡 선택 복귀 시 남은 효과음을 정리하며 타격 이펙트 강도와 시스템 ‘동작 줄이기’를 적용합니다.

## 판정과 시간 기준

| 판정 | 노트 시점과의 차이 | 점수 가중치 |
| --- | --- | --- |
| PERFECT | ±45 ms 이내 | 1.0 |
| GREAT | ±90 ms 이내 | 0.7 |
| GOOD | ±140 ms 이내 | 0.3 |
| MISS | 늦게 140 ms를 초과하거나 끝까지 미입력 | 0 |

점수는 `가중치 합 / 전체 노트 수 × 1,000,000`입니다. 정확도는 처리된 노트의 가중치 평균이며, 곡이 끝나면 전체 노트 기준이 됩니다. 등급은 S ≥99%, A ≥95%, B ≥85%, C ≥70%, D <70%입니다.

기본 곡의 음악 버퍼와 채보는 같은 BPM 그리드를 사용합니다. 노트 위치와 판정은 프레임 수 대신 Web Audio의 출력 시계에서 계산합니다. 가능한 브라우저에서는 [AudioContext.getOutputTimestamp()](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp)로 출력 시각을 브라우저 입력 시각에 대응시킵니다. 지원하지 않는 환경에서는 오디오 시각과 출력 지연 정보를 사용합니다.

싱크 보정의 양수 값은 노트의 표시·판정 시점을 늦춥니다. 노트 속도를 바꿔도 음악 속도나 판정 범위는 바뀌지 않습니다.

## 확인 명령

```sh
npm test
npm run check
npm run verify:demo
```

단위 검사는 56개입니다. `verify:demo`는 단위·문법 검사와 설치된 Chrome/Chromium의 임시 프로필을 사용하는 23개 브라우저 흐름 검사를 한 번에 실행합니다. 4키 TIDAL CIRCUIT 168노트와 6키 AFTERGLOW 78노트를 각각 실제 시간으로 완주하며 약 3분이 걸립니다. ASTRAL 6키의 전 노트 PERFECT는 단위 검사와 발표 영상 렌더에서 확인하며 위 23개 자동 브라우저 흐름에는 포함하지 않습니다. 결과·PNG·SHA-256·오류 로그는 Git에서 제외된 `artifacts/demo-qa/`에 저장됩니다. 사용자의 Chrome 탭을 사용하거나 브라우저를 자동 설치하지 않으며, 브라우저 검증이 불가능하면 실패로 반환합니다. 실행 조건과 산출물 설명은 [DEMO.md](DEMO.md)를 확인하세요.

2026-10-07 LP 전체 아트·선택곡 자동 미리듣기 변경은 단위 54개와 문법 검사를 통과했습니다. 인앱 브라우저에서 세 곡 전환·반복 재생, 기본 대기 음악 꺼짐 상태의 자동 미리듣기, 수동 정지 유지·중앙 커버 재선택, 설정·도움말·음소거·게임 진입/메뉴 복귀, 375px 화면의 전체 아트와 가로 넘침 없음을 확인했습니다. 예상 밖 콘솔 오류는 없었습니다. 이번 변경에서 전체 곡 23개 회귀 흐름은 재실행하지 않았으며, 실제 청감과 모바일 기기는 별도 확인 범위입니다.

헤더 타이틀 변경 후 아이콘 제거·타이틀 크기·홈 링크 접근성 이름, 설정·도움말 버튼, 320px·375px 가로 넘침 없음을 브라우저에서 확인했습니다. 음악 추가 단계의 전체 재생·기록 분리 및 이전 23개 회귀 흐름 결과는 [DEMO.md](DEMO.md)에 따로 기록합니다. 실제 청감·물리 키보드 지연·모바일 터치는 별도 확인 범위입니다.

판정 경계, 중복 입력, 미입력, 동시 노트, 싱크 보정, 채보 범위와 최종 점수, 곡별 버퍼 선택, 첫 음악 준비 요청, 출력 시각 변환과 재개 시 시계 처리를 검증합니다. 콤보 보상 주기·MISS 후 중복 방지·재시도 초기화, 음악과 효과음의 개별 음량, 효과 정리, 콤보 효과음 합성·캐시·외부 SFX 차단 중 재생·미리듣기 교체·재생 중 음소거도 검증합니다. 브라우저에서 세 곡 선택과 미리듣기, 실제 노트 이동과 입력 반응, 곡 종료, 메뉴 복귀, 일시정지·재개도 함께 확인합니다.

## 검증 범위와 자산 출처

브라우저 검사는 음소거된 헤드리스 Chrome의 오디오 시계·PCM·자동 입력을 확인합니다. 실제 청감, 물리 입력 지연, 주관적 재미와 모바일 터치 성능은 수동 리허설 대상입니다.

기본 곡과 효과음은 직접 작성한 합성 코드, 앨범 아트와 워드마크는 SVG로 구성합니다. 시스템 TTS·외부 음성 샘플·개인 음원은 포함하지 않습니다. 직접 합성한 대기 음악 WAV와 재생성 코드는 함께 제공합니다. DJMAX 등은 화면·장르의 영감이며 공식 제휴나 원본 자산 사용을 주장하지 않습니다.
