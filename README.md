# PULSE SHIFT

두 오리지널 곡을 연주하는 브라우저 리듬 게임입니다. CD 플레이어에서 곡을 고르고 원근 레인으로 다가오는 노트를 D·F·J·K로 입력합니다. 버전 0.6.0의 발표용 독립 스냅샷이며, 기본 4키와 AFTERGLOW LEVEL 1 전용 6키 실험을 제공합니다.

소스 저장소: [perspicacia/pulse-shift-demo](https://github.com/perspicacia/pulse-shift-demo). 이 주소는 소스 검토용이며 게임은 아래 명령으로 로컬에서 실행합니다. 검증 절차와 한계는 [DEMO.md](DEMO.md), 포함 기능은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 런타임 패키지가 없어 `npm install`은 필요하지 않습니다.

```sh
git clone https://github.com/perspicacia/pulse-shift-demo.git
cd pulse-shift-demo
npm run dev
```

서버가 실행되면 같은 컴퓨터의 Chrome 주소 표시줄에 `http://localhost:4173`을 입력합니다. 실행 터미널은 유지하고 종료할 때 `Ctrl+C`를 누릅니다. 서버가 브라우저를 자동으로 열지는 않습니다. 포트가 사용 중이면 `PORT=4183 npm run dev`로 실행하고 `http://localhost:4183`을 엽니다. 다른 컴퓨터에서는 이 컴퓨터의 localhost 주소로 접속할 수 없습니다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 왼쪽부터 4개 레인 | D · F · J · K |
| AFTERGLOW LEVEL 1 전용 6키 실험 | S · D · F / J · K · L |
| 곡 선택 | 메뉴에서 ← · → 또는 플레이어의 좌우 버튼 / 커버 클릭 |
| 일시정지 / 재개 | Esc |
| 곡 시작 / 일시정지 후 재개 | Enter 또는 화면 버튼 |
| 터치 입력 | 플레이 화면 아래의 레인 버튼 |

키를 계속 누르고 있어도 노트가 자동으로 처리되지 않습니다. 동시 노트는 각각의 키를 함께 누릅니다. 창이 포커스를 잃거나 다른 탭으로 이동하면 자동으로 일시정지됩니다.

기본은 4키입니다. AFTERGLOW LEVEL 1에서만 **6키 실험**을 선택할 수 있고, 동시에 최대 두 노트가 나옵니다. 점수 기록은 `곡:4k:레벨`과 `곡:6k:레벨`로 분리하며 이전 4키 기록도 계속 읽습니다. TIDAL CIRCUIT을 선택하면 4키로 돌아옵니다. 마지막으로 고른 키 모드는 설정에 저장되므로 본 시연 전에는 **4 KEY · 기본**을 선택하세요. 자세한 범위와 검증은 [DEMO.md](DEMO.md)를 확인하세요.

## 포함된 기능

- 오리지널 곡 **AFTERGLOW** — PULSE LAB, 148 BPM, 약 67초.
- 오리지널 곡 **TIDAL CIRCUIT** — PULSE LAB, 132 BPM, 약 76초. 모듈러 신스·깊은 베이스·스윙이 있는 브로큰 비트.
- 4키 LEVEL 1 / LEVEL 2 / LEVEL 3 난이도와 일반 노트, 동시 노트. 6키 실험은 AFTERGLOW LEVEL 1만 지원.
- 노트 속도 ×1.0–×6.0, 싱크 보정 −200–+200 ms.
- 판정선의 팝·링·별빛 입자와 판정·콤보 팝 애니메이션, 음정 없는 짧고 부드러운 타격음.
- 첫 10콤보와 이후 50·100·150콤보의 축하 효과음·배너·컨페티. 같은 구간은 곡당 한 번만 보상.
- 일반 PERFECT·GREAT·GOOD 입력에는 짧은 타격음과 화면 판정만 표시.
- 음악·타격음·콤보 효과음의 개별 볼륨, 타격 이펙트 강도와 타격음·콤보 효과음 미리듣기.
- 판정, 콤보, 최고 콤보, 정확도, 점수, 결과 등급.
- 곡별·키 개수별·레벨별 최고 기록과 설정을 브라우저의 로컬 저장소에 저장.
- 미리듣기, 시작 카운트다운, 일시정지, 재시도, 곡 선택으로 복귀.
- 중앙 CD 플레이어와 양옆 앨범 커버로 곡 선택. 좌우 키로 중앙에 넣고 Enter로 시작하며 미리듣기 중에는 디스크가 회전.
- 작은 화면 대응과 터치 레인 버튼, 키보드로 조작 가능한 메뉴.

## 오리지널 곡 선택

첫 대기 화면의 **LOBBY RADIO — NEON HALO**는 128 BPM의 오리지널 사이버 팝 루프입니다. 반짝이는 FM 아르페지오, 넓게 퍼지는 신스 패드, 음성처럼 들리는 합성 코러스, 엇박 베이스와 디지털 퍼커션으로 구성됩니다. Grimes의 [Artificial Angels 공식 영상](https://www.youtube.com/watch?v=tvGnYM14-1A)을 분위기 참고로 삼았으며, 음악과 코러스는 코드로 새로 합성합니다.

브라우저의 자동재생 제한 때문에 **첫 클릭이나 키 입력** 뒤에 시작합니다. **켜기 / 끄기** 버튼으로 조작하고, 설정의 **대기 음악 볼륨**으로 플레이 음악과 별도로 음량을 조절할 수 있습니다. 끄기와 음량 설정은 저장됩니다. 곡 선택 중에는 계속 흐르고, 곡 미리듣기·플레이·설정 화면·숨겨진 탭에서는 잠시 멈춥니다. 메뉴로 돌아오면 다시 흐릅니다. 직접 합성한 기본 WAV 음원을 한 번 읽고 캐시하며, 잔향을 루프 앞부분으로 이어 자연스럽게 반복합니다. 대기 음악은 플레이 곡 목록과 판정 시계를 바꾸지 않습니다.

상단 **CD 플레이어**에서 **←·→** 키, 좌우 이동 버튼 또는 양옆 커버를 눌러 **AFTERGLOW**와 **TIDAL CIRCUIT**을 고릅니다. 중앙에 들어온 CD가 선택된 곡입니다. 제목, BPM, 길이, 채보, 최고 기록이 함께 바뀌며, 방향키로 이동한 뒤 **Enter**로 바로 시작할 수 있습니다. 빠르게 곡을 넘겨도 마지막 선택이 유지되고, 설정의 슬라이더와 플레이 중 입력에는 곡 이동 키가 적용되지 않습니다.

플레이어 가운데 **미리듣기** 버튼으로 들어볼 수 있으며 재생 중에는 디스크가 회전합니다. 시스템의 ‘동작 줄이기’ 설정에서는 커버 이동과 회전을 끕니다. 오리지널 곡은 최초 사용 시 워커에서 합성하고, 이후에는 곡별 캐시를 재사용합니다.

**TIDAL CIRCUIT**은 Bonobo의 ID700을 참고해 모듈러 신스와 영국풍 전자음악의 분위기를 바탕으로 작곡한 새 오리지널 곡입니다. 자체 FM 플럭, 마이너·메이저 확장 화음, 서브 베이스, 엇박 킥과 스윙 하이햇을 사용하며, 인트로 → 그루브 → 브레이크다운 → 두 번째 그루브 → 아웃트로로 구성됩니다. 원곡의 음원이나 샘플을 사용하지 않습니다. 참고: [Bonobo의 공식 트랙 소개](https://music.apple.com/us/album/distance-in-static/1895659203).

LEVEL 1·2·3 채보는 각각 85·168·381개 노트로 구성됩니다. 합성과 채보가 동일한 악기 이벤트를 공유하므로, 스윙과 엇박도 실제 악기가 나오는 시점에 맞춰집니다. 기본 곡의 이전 버전 기록도 AFTERGLOW에서 이어서 볼 수 있습니다.

## 앨범 배경과 원근형 플레이 화면

선택한 곡의 앨범 커버를 무대 전체 배경으로 사용합니다. 커버 불투명도는 `playfield.css`의 `--album-opacity: .28`이며, 어두운 그라데이션을 겹쳐 노트와 판정선이 구분되게 합니다. 두 곡은 각자의 커버를 사용합니다. 배경 이미지는 장식이며 입력을 가로채지 않습니다.

레인·노트·박자선은 같은 원근 좌표로 그립니다. 멀리서 작게 나타난 노트가 판정선으로 다가오며 커지고, 정확한 노트 시각에 각 입력 버튼의 중앙을 지납니다. 표시 방식만 변경하며 판정 범위·채보·오디오 출력 시계·점수 공식은 유지합니다. 타격 입자는 판정선의 같은 좌표에서 발생합니다. 점수와 정확도는 상단, 콤보는 레인 옆에 표시하고 작은 화면에서는 보조 정보를 줄입니다. 4키와 6키 모두 같은 무대 구조를 사용합니다.

사용자가 제공한 화면은 원근 레인과 무대 구성의 참고로만 사용했습니다. 배경·커버는 프로젝트의 기존 SVG이며 참고 게임의 이미지·음원을 추가하지 않았습니다.

헤더의 PULSE SHIFT는 칼날 같은 세리프와 사선 절개를 직접 그린 은색 SVG 워드마크입니다. 외부 폰트 없이 표시하며 작은 화면에 맞춰 크기를 줄입니다. 홈 링크의 접근성 이름은 `PULSE SHIFT 홈`으로 유지합니다.

## 타격 효과와 콤보 효과음

콤보 효과음은 **연속 10콤보, 이후 50·100·150…콤보**에서만 나옵니다. PERFECT·GREAT·GOOD 모두 콤보를 이어가고 MISS는 끊습니다. 콤보가 끊겼다가 같은 구간에 다시 도달해도 이미 받은 보상은 반복되지 않습니다. 다시 플레이하면 보상 일정도 초기화됩니다. 일반 판정이나 누적 PERFECT 횟수만으로는 콤보 효과음이 나오지 않습니다.

플레이 화면의 **COMBO REWARD**는 다음 미획득 보상까지의 연속 콤보를 표시하며 MISS 시 진행량이 줄어듭니다. 해당 곡의 노트 수로 도달 가능한 보상을 모두 받으면 ‘보상 완료’로 표시합니다.

콤보 효과음은 코드로 직접 합성합니다. 첫 10콤보에는 가벼운 0.30초 전자음을, 50콤보 이상에는 조금 더 풍성한 0.48초 전자음을 재생합니다. 낮은 음량으로 음악에 섞으며 음악 음량이나 재생 시계를 바꾸지 않습니다. 외부 음성 파일을 내려받지 않고 두 버퍼를 캐시합니다. 효과음 구현은 [assets/sfx/README.md](assets/sfx/README.md)에 설명합니다.

모든 레인의 타격음은 음정 없는 짧은 퍼커션이며 조용한 구간에서는 더 작아집니다. 설정의 **타격음 듣기 / 10콤보 듣기 / 50콤보 이상 듣기**로 확인하고 음악·타격음·콤보 효과음 음량을 따로 조절할 수 있습니다. 콤보 효과음 0%는 재생 중인 효과음도 정리합니다. 재시도·곡 선택 복귀 시 남은 효과음을 정리하며 타격 이펙트 강도와 시스템 ‘동작 줄이기’를 적용합니다.

## 판정과 시간 기준

| 판정 | 노트 시점과의 차이 | 점수 가중치 |
| --- | --- | --- |
| PERFECT | ±45 ms 이내 | 1.0 |
| GREAT | ±90 ms 이내 | 0.7 |
| GOOD | ±140 ms 이내 | 0.3 |
| MISS | 늦게 140 ms를 초과하거나 끝까지 미입력 | 0 |

점수는 `가중치 합 / 전체 노트 수 × 1,000,000`입니다. 정확도는 처리된 노트의 가중치 평균이며, 곡이 끝나면 전체 노트 기준이 됩니다. 등급은 S ≥99%, A ≥95%, B ≥85%, C ≥70%, D <70%입니다.

기본 곡의 음악 버퍼와 채보는 같은 BPM 그리드를 사용합니다. 노트 위치와 판정은 프레임 수 대신 Web Audio의 출력 시계에서 계산합니다. 가능한 브라우저에서는 [AudioContext.getOutputTimestamp()](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp)로 출력 시각을 브라우저 입력 시각에 대응시킵니다. 지원하지 않는 환경에서는 오디오 시각과 출력 지연 정보를 사용합니다.

싱크 보정의 양수 값은 노트의 표시·판정 시점을 늦춥니다. 노트 속도를 바꿔도 음악 속도나 판정 범위는 바뀌지 않습니다.
