# 개인 음악과 박자 보정 (실험 브랜치)

`codex/personal-music-sync`에서 음악 불러오기를 제공합니다. 기존 세 오리지널 곡도 그대로 플레이할 수 있습니다.

1. 시작 화면의 **음악 불러오기**에서 파일을 선택합니다.
2. 자동 추정한 **BPM**과 **첫 박 위치**를 확인합니다. 템포가 절반/두 배로 잡혔다면 해당 버튼을 사용합니다.
3. **적용하고 10초 테스트**로 실제 음악과 노트를 확인합니다. 시작(첫 박 근처)·중간·끝 중 골라 최대 10초를 재생하며 기록을 저장하지 않습니다. 후반부도 비교하면 BPM 오차를 확인하기 쉽습니다.
4. 일정하게 어긋나면 첫 박 위치(±10ms), 뒤로 갈수록 어긋나면 BPM을 조정합니다. 기기 출력 지연은 기존 게임 설정의 싱크 보정으로 조정합니다.
5. **적용하고 곡 선택**으로 돌아가 4키 또는 6키, LEVEL 1·2·3으로 전체 곡을 플레이합니다. **박자·노트 보정**으로 다시 조정할 수 있습니다.

MP3·WAV 등 브라우저가 디코딩할 수 있는 파일을 지원합니다. 파일은 40MB 이하, 12초~5분, 모노/스테레오로 제한합니다. 포맷 지원은 브라우저에 따라 다릅니다. 실패하거나 분석 중 창을 닫아도 이전 선택곡을 유지합니다. 개인 곡은 한 번에 하나를 보관하며, 교체하거나 음악 빼기를 하면 이전 버퍼를 해제합니다.

## 싱크와 자동 채보

파일을 먼저 완전히 디코딩한 뒤 음악 재생 시각을 기준으로 노트 위치와 입력을 계산합니다. 기존 음악 시계와 판정 범위는 바꾸지 않습니다. 파형의 에너지·저음·고음 변화와 반복 간격으로 BPM/첫 박을 추정하고, 검출한 소리 시작점을 보정한 박자 그리드에 배치합니다. 원본 PCM의 복사본을 워커에 전송하며 특징 추출과 박자 추정 모두 워커에서 수행합니다. 재생 중에는 분석하지 않습니다.

BPM과 첫 박을 수정하면 표시 정보뿐 아니라 실제 채보 시각이 바뀝니다. 난이도는 노트 밀도·두 손 동시 입력을 바꾸고, 노트 속도 설정은 그대로 별개입니다. 생성 채보는 일반 노트만 포함하며 롱노트 길이나 악기별 멜로디를 추정하지 않습니다.

**박자가 일정한 곡을 위한 실험 기능**입니다. 템포 변화·스윙·박자가 흐릿한 구간·복잡한 믹스는 정확하지 않을 수 있고, 모든 곡에 완벽한 채보를 보장하지 않습니다. 전역 BPM 그리드만 사용하므로 템포가 바뀌는 곡은 한 번의 보정으로 전 구간을 맞출 수 없습니다. 분석 결과가 불확실하거나 구간별 박자 일치가 낮으면 안내합니다. 자연스러운 난이도와 청감은 실제 곡으로 별도 확인이 필요합니다.

## 파일과 기록

파일 선택은 업로드가 아닙니다. 음악·파일명·PCM·채보를 서버나 GitHub에 전송하지 않고 브라우저 메모리에서만 처리합니다. 새로고침 후에는 파일을 다시 선택해야 합니다. 파일 바이트의 SHA-256 식별자와 보정값(BPM·첫 박), 모드별 최고 기록만 이 브라우저에 저장합니다. 같은 파일을 다시 선택하면 보정값을 불러옵니다. 보정값·키 개수·레벨별로 기록을 분리하며 기존 곡 기록과 섞지 않습니다.

## 검증

`npm test`, `npm run check`를 실행합니다. 합성한 알려진 BPM의 클릭음으로 90·120·128.5·160 BPM, 무음 도입부, 5분 곡의 시간 누적 오차, 반대 위상 스테레오, 무음 실패, 템포 변화 안내, 보정 후 실제 노트 시간 이동, 모든 개인 4/6키 채보의 완주를 검사합니다. 이는 실제 사용자 음악·장치에서의 정확도를 보장하는 수치가 아닙니다.

브라우저에서 파일 선택·워커 분석·10초 테스트·전체 곡 진행·일시정지·재시도·다른 곡 복귀·분석 실패/취소·보정값 유지·파일 교체를 확인합니다. 실제 사용자 곡은 제공받지 않았으므로 그 곡의 자동 분석 품질과 실제 스피커/블루투스 청감은 별도로 검증해야 합니다.
