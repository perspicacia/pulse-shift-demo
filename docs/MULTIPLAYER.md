# 2인 멀티 플레이 · 실험 기능

같은 곡과 LEVEL로 두 명이 함께 시작해 점수를 비교합니다. 오리지널 곡 5개, 4키 LEVEL 1·2·3을 지원합니다. 개인 음악과 6키는 기존 솔로에서 플레이합니다.

## 시작하기

1. Node.js 22 이상에서 `npm run dev`로 실행한 게임 주소를 양쪽에서 엽니다.
2. **2인 멀티**를 열고 닉네임을 입력합니다. 한 명은 **새 방 만들기**, 다른 한 명은 6자리 코드로 참가합니다.
3. 호스트가 곡과 LEVEL을 고릅니다. 변경하면 두 사람의 READY가 초기화됩니다.
4. 각자 **음악 준비하고 READY**를 누릅니다. 두 브라우저의 음악 준비와 서버 시각 확인이 완료되면 공통 카운트다운으로 시작합니다.
5. 상대 점수·콤보·정확도를 보면서 플레이합니다. 결과 화면에서 두 사람의 점수를 비교하고, 재대전 준비로 같은 방에서 다시 플레이할 수 있습니다.

멀티 결과는 솔로 최고 기록에 저장하지 않습니다. 개인 음악 파일·분석 결과·채보는 네트워크로 전송하지 않습니다. 방에는 닉네임, 오리지널 곡 ID, LEVEL, 준비 상태, 숫자 점수 요약만 전송합니다.

## 연결과 시작 시각

- Node 내장 HTTP 서버와 EventSource(SSE)를 사용합니다. 추가 런타임 패키지는 없습니다.
- 서버 메모리의 방은 최대 2명이며, 플레이어마다 별도의 무작위 인증 토큰을 발급합니다. 공개 방 상태에는 토큰을 포함하지 않습니다.
- 브라우저가 서버 시각을 5회 확인하고 가장 작은 왕복 지연의 중간 시각으로 오차를 추정합니다. 최소 왕복 지연이 350ms를 넘으면 준비를 중단합니다.
- 두 명 모두 READY인 때 서버가 한 번만 경기 ID와 4초 후의 공통 시작 시각을 만듭니다. 양쪽은 이 시각을 각자의 AudioContext 출력 시계로 옮겨 음악을 예약합니다. 입력 판정과 노트 위치는 계속 각 브라우저의 음악 시계를 기준으로 계산합니다.
- 네트워크 점수 갱신은 최대 4회/초이며 판정 경로에 포함하지 않습니다. 늦은 경기 ID·준비 버전·방 갱신은 무시하거나 거절합니다.
- 시작 안내가 너무 늦거나 오디오 준비·시각 추정이 만료되면 경기를 취소하고 다시 READY하도록 안내합니다.

시각 추정은 네트워크 지연이 비대칭이면 오차가 생길 수 있습니다. 각 기기의 실제 출력 지연·키보드 입력 지연을 동일하게 만드는 기능은 아닙니다. 음악과 입력 보정은 기존 게임 설정을 사용합니다.

## 중단·재접속

- 경기 중 **경기 중단** 또는 ESC를 누르면 두 사람의 경기를 중단합니다. 멀티 경기에서 개인 일시정지는 제공하지 않습니다.
- 탭을 숨기거나 SSE 연결이 끊기면 경기와 READY가 초기화됩니다. 다른 창에 포커스를 옮기는 것만으로는 중단하지 않습니다.
- EventSource는 자동 재접속합니다. 연결이 돌아와도 중단된 경기를 이어서 재생하지 않으며, 같은 방에서 두 사람 모두 다시 READY해야 합니다.
- 연결이 끊긴 플레이어는 45초 후 방에서 제거됩니다. 호스트가 나가면 남은 플레이어에게 호스트가 넘어갑니다. 두 사람이 모두 나가면 방은 삭제됩니다.
- 방 데이터는 서버 메모리에만 보관합니다. 서버를 재시작하면 방이 사라지고 새로고침한 브라우저는 코드로 다시 참가해야 합니다.

## 로컬과 외부 접속

기본 서버는 `127.0.0.1`에만 바인딩됩니다. 같은 컴퓨터의 서로 보이는 두 브라우저/창으로 확인할 수 있습니다. 동일 브라우저의 숨겨진 탭은 경기 중단 정책에 해당합니다.

LAN 테스트가 필요하면 실행자가 명시적으로 `HOST=0.0.0.0 PORT=4185 npm run dev`를 설정하고 두 기기가 동일한 LAN 주소를 엽니다. 방 생성·참가는 같은 Origin에서만 가능합니다. HTTPS 역방향 프록시를 사용할 때는 실행자가 `PUBLIC_ORIGIN=https://게임주소`를 설정해야 합니다. 공개 서버 운영·TLS·방화벽·지속 저장·부하 분산은 이번 구현 범위에 포함하지 않습니다.

GitHub Pages는 정적 호스팅이므로 방 서버가 없습니다. 멀티 요청에는 Node 서버 주소에서 이용하라는 안내를 표시하고 솔로는 계속 사용할 수 있습니다.

## 검증과 제한

`tests/multiplayer-server.test.mjs`는 2인 제한, 호스트 설정, READY 버전, 중복 시작 방지, 점수 범위·경기 ID·종료 시각, 공통 SSE 시작, 연결 중단·재접속·호스트 이전·만료를 확인합니다. `tests/multiplayer.test.mjs`는 시각 추정, 느린 연결, 이전 스트림·방 응답 무시, 호스트의 곡·LEVEL 변경 유지, 점수 전송 간격, 진행 중 전송 뒤의 최종 결과와 이전 경기 결과 폐기, 정적 호스팅 안내를 확인합니다. 브라우저 검증 결과는 `DEMO.md`에 별도로 기록합니다. 두 클라이언트 완주·상대 점수와 승패·재대전 첫/둘째 READY·ESC 양쪽 중단·방 나가기와 솔로 복귀를 확인했습니다.

프로토타입은 클라이언트의 판정과 점수 요약을 신뢰합니다. 서버의 형식·범위 검증은 조작 방지 기능이 아니며, 경쟁 서비스에 필요한 서버 판정·치트 방지·계정·랭킹·매치메이킹은 지원하지 않습니다. 인터넷 및 서로 다른 실제 오디오 장치에서의 체감 동시성은 아직 보장하지 않습니다.
