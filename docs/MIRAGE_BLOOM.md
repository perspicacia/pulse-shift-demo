# MIRAGE BLOOM

PULSE LAB의 오리지널 월드 라운지 곡. Eden의 **Mavis**에서 느껴지는 차분하고 몽환적인 라운지 방향을 참고하되, 선율·코드 진행·리듬·사운드는 이 프로젝트에서 새로 작성했다. 원곡 오디오·멜로디·가사·샘플을 사용하지 않는다.

- **112 BPM**, 32마디와 잔향을 포함해 약 **72초**.
- 숨결이 섞인 플루트 리드, 부드러운 플럭, 둥근 손 타악, 셰이커, 저음 드론과 넓은 패드.
- 도입 4마디 → 그루브 8마디 → 조용한 브리지 4마디 → 리드가 돌아오는 그루브 12마디 → 아웃트로 4마디.
- 4키 **LEVEL 1·2·3**. 낮은 레벨은 큰 박과 주요 선율, 높은 레벨은 손 타악과 플럭의 엇박까지 연주한다. 최대 두 동시 노트, 같은 레인 간격 200ms 이상이며 롱노트는 없다.

`src/mirage-score.js`의 동일 악보가 합성과 채보를 만든다. 노트 시각은 실제 악기 이벤트의 시각에서 선택하며 프레임 수나 별도 추정 BPM에 의존하지 않는다. `src/synth-mirage.js`는 시드가 고정된 잡음과 직접 만든 오실레이터·필터·엔벨로프·스테레오 딜레이로 PCM을 생성한다. 별도 다운로드나 음원 파일이 필요하지 않다.

앨범 아트는 직접 작성한 SVG다. 정사각 커버와 원판 전체용 아트를 따로 제공하며, 원판 제목은 원형 인쇄 안전 영역 안에 배치했다.

`node --test tests/mirage.test.mjs`는 세 채보의 악보 시각·밀도·레인 간격·동시 입력과 Session의 PERFECT 완주, 합성의 결정성·양 채널·유한 샘플·헤드룸·구간별 음량·끝 페이드를 확인한다. 브라우저에서 곡 선택·미리듣기·실제 전체 재생 검증은 통합 작업에서 별도로 확인한다.
