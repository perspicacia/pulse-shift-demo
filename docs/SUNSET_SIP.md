# SUNSET SIP

해변의 저녁을 떠올리는 따뜻한 오리지널 라운지 곡입니다. 106 BPM, 32마디, 약 75.45초로 구성했으며 외부 음원·샘플·녹음을 사용하지 않습니다. Boris Blenn의 Beachbar에서 사용자가 좋아한 편안한 라운지 분위기를 참고하고, 멜로디·화성 배치·악기 악보는 자체 작성했습니다.

## 음악 구성

- 전자피아노: Fmaj9·Dm9·Gm9·C13sus 계열의 7·9도 화음과 부드러운 타인 음색.
- 베이스: 둥근 저음과 짧은 배음으로 만든 유기적인 워킹 패턴.
- 리듬: 느긋한 킥, 브러시 스네어, 살짝 늦춘 셰이커, 짧은 림 소리.
- 공간: 넓게 배치한 패드와 조용한 파도 같은 합성 노이즈, 짧은 스테레오 반사음.
- 흐름: 도입 4마디 → 그루브 10마디 → 쉬어가는 4마디 → 다시 펼쳐지는 12마디 → 마무리 2마디.

`src/sunset-score.js`의 악기 이벤트 하나를 합성과 채보가 함께 사용합니다. 스윙이 적용된 악기 시점도 실제 노트 시점에 반영합니다. 4키 LEVEL 1·2·3은 노트 밀도로 구분하며 LEVEL 1은 단일 입력, LEVEL 2·3은 최대 두 동시 입력으로 구성했습니다. 같은 레인의 입력 간격은 최소 200ms입니다. 롱노트와 6키 채보는 이 곡에 추가하지 않았습니다.

## 제작 파일

- `src/sunset-score.js`: 오리지널 악보, 곡 정보, 3개 난이도 채보.
- `src/synth-sunset.js`: 결정적인 스테레오 PCM 합성. 기본 44.1kHz이며 호출 시 샘플레이트를 지정할 수 있습니다.
- `assets/sunset-sip.svg`: 정사각형 커버.
- `assets/sunset-sip-disc.svg`: 원판 전체에 인쇄하는 전용 아트. 제목은 원형 안전 영역에 배치했습니다.

## 검증

`node --test tests/sunset.test.mjs`는 곡 길이, 유한한 PCM 값, 헤드룸, 스테레오 차이, 조용한 중간 구간과 복귀, 동일한 합성 결과를 확인합니다. 채보는 실제 악기 시작 시점, 밀도 차이, 동시 입력 수, 레인 간격을 검사하며 세 난이도 모두 정확한 시점 입력으로 Session이 1,000,000점·풀 콤보로 끝나는지 확인합니다. 실제 청취와 브라우저 미리듣기·플레이 검증은 별도로 확인해야 합니다.
